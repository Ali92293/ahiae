# عالَم الخلية ثلاثي الأبعاد 🧬

موقع تعليمي عربي تفاعلي لتعلم الخلية الحيوانية والنباتية باستخدام **HTML + CSS + JavaScript + Three.js**.

---

## 📁 محتويات المشروع

| الملف | الوصف |
|------|------|
| `index.html` | هيكل الصفحة الرئيسية مع دعم RTL والوصولية (ARIA) |
| `styles.css` | تنسيق احترافي مع خطوط عربية (Cairo + Tajawal) |
| `data.js` | بيانات العضيات العشر + جدول المقارنة |
| `cell-scene.js` | فئة `CellScene` لإدارة المشهد ثلاثي الأبعاد |
| `app.js` | فئة `AppUI` للتحكم بالواجهة والأحداث |
| `tests/test-syntax.js` | فحص صياغة JavaScript + سلامة البيانات |
| `tests/test-comprehensive.js` | فحص شامل (126 فحصًا) |
| `tests/puppeteer-test.js` | اختبار تفاعلي فعلي عبر Puppeteer (يتطلب WebGL) |
| `README.md` | هذا الملف |
| `AUDIT_REPORT.md` | تقرير تدقيق الأخطاء وإصلاحاتها |
| `TEST_REPORT.md` | تقرير الاختبارات المنفذة فعليًا |

---

## 🚀 كيفية التشغيل

### الطريقة الأولى: فتح مباشر
انقر مرتين على ملف `index.html` لفتحه في المتصفح.

### الطريقة الثانية: خادم محلي (مُوصى بها)
```bash
# باستخدام Python
python3 -m http.server 8000

# أو باستخدام Node.js
npx serve
```
ثم افتح المتصفح على: `http://localhost:8000`

## ⚠️ التعامل مع فشل WebGL

إذا لم يدعم متصفحك WebGL، سيظهر لك:

- رسالة عربية واضحة تشرح المشكلة.
- زر **«إعادة المحاولة»** لمحاولة تحميل المشهد مرة أخرى.
- زر **«تصفّح العضيات»** للانتقال مباشرة إلى البطاقات التعليمية وجدول المقارنة.

**البطاقات والجدول يعملان دائمًا بغض النظر عن حالة WebGL.**

## 🔬 ملاحظة علمية

النموذج ثلاثي الأبعاد المعروض هنا **تعليمي ومبسّط**، ولا يمثل بالضرورة الأبعاد أو النسب الحقيقية للعضيات داخل الخلية. الهدف هو توضيح الوظائف الأساسية لكل عضية بصورة ميسّرة.

للحصول على معلومات دقيقة عن الأبعاد والتركيب الدقيق، يُرجى الرجوع إلى المراجع العلمية المعتمدة في علم الأحياء الخلوي.

## 🧪 الاختبار

### اختبارات الكود (لا تتطلب WebGL)
```bash
# فحص صياغة + سلامة البيانات
node tests/test-syntax.js

# فحص شامل (126 فحصًا)
node tests/test-comprehensive.js
```

**النتيجة المتوقعة**:
- `test-syntax.js`: ✅ جميع الفحوص نجحت، لا أخطاء
- `test-comprehensive.js`: ✅ نجح: 126، فشل: 0، تحذيرات: 0

### اختبار تفاعلي فعلي (يتطلب WebGL)
```bash
# تثبيت puppeteer-core أولاً
npm install puppeteer-core

# تشغيل الاختبار (يفترض خادم HTTP على localhost:3000)
CHROME_PATH=/path/to/chrome node tests/puppeteer-test.js
```

يختبر هذا الاختبار فعليًا:
- تهيئة WebGL والمشهد
- النقر على العضيات وفتح النوافذ
- التمييز بين النقرة والسحب
- زر إظهار/إخفاء الأسماء
- التبديل بين الخلية النباتية والحيوانية
- التكبير والتصغير
- التجاوب على شاشة الموبايل

انظر `TEST_REPORT.md` للاطلاع على النتائج الفعلية الموثقة.
